# Changelog

## 1.0.0 - 2026-09-20

Initial stable release of Ail.

- Strict versioned JSON program representation.
- Deterministic evaluator and validation.
- Variables, expressions, functions, control flow, errors, and local modules.
- Prompts, LLM calls, tools, bounded agents, memory, context, streaming, and structured output.
- Offline deterministic MockProvider.
- Standard-library OpenAI provider with normal and SSE streaming requests.
- Deterministic Go and Java target emitters.
- CLI, REPL, tests, examples, scripts, and documentation.
